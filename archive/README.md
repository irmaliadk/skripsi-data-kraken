perkembangan kode. GitHub Actions tidak menjalankan workflow dari direktori
ini. Implementasi yang dipakai untuk Bab 5 berada di `scripts/thesis_core/`,

sebelum refaktor. Keduanya dipakai untuk pemeriksaan regresi, bukan untuk
menentukan hasil penelitian baru.
